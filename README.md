# dMAT Practice (unofficial)

An open-source, static mock exam for the [dMAT (Digitaler Mastertest)](https://www.d-mat.de/en/) —
the digital study aptitude test used by German universities to admit international applicants to
Master's programmes.

**Not affiliated with g.a.s.t. or dMAT.** This project is built independently from the publicly
available dMAT preparatory materials to help with personal exam prep, and is shared in case it's
useful to others. All exercises are freshly generated, original content — nothing is copied from
the official materials.

No backend, no database, no accounts. Everything runs client-side and is hostable as-is on GitHub
Pages.

## What's here

- **Latin Squares** (Core Module) — a 5×5 grid where each letter appears once per row/column;
  figure out the letter hidden behind the `?`. 20 questions, 25-minute timer, matches the dMAT UI
  chrome (timer bar, module breadcrumb, question navigator, font-size controls).

More Core Module subtests (Figure Sequences, Mathematical Equations) and the Subject Module are
planned — see the disabled cards on the home page.

## Project structure

```
index.html                     Landing page / module picker
latin-squares.html             Latin Squares subtest UI
css/style.css                  Shared styles (dMAT-style magenta branding)
js/latin-squares.js            Exam logic: timer, navigation, scoring, answer state
js/latin-squares-data.js       Generated puzzle bank (committed, human-readable JSON wrapped in JS)
data/latin-squares.json        Same puzzle bank as plain JSON (source of truth)
scripts/generate-latin-squares.js   Node script that generates the puzzle bank
```

### Regenerating puzzles

Puzzles are generated by `scripts/generate-latin-squares.js`: it builds a random 5×5 Latin
square, then greedily hides clues while checking — via the same "only one letter is missing from
this row/column" elimination a test-taker would use — that the `?` cell stays logically
deducible. Difficulty ramps across the 20 questions (fewer starting clues = more deduction
steps).

```bash
node scripts/generate-latin-squares.js   # writes data/latin-squares.json
```

After regenerating the JSON, re-embed it as a JS global (needed so the page also works when
opened directly via `file://`, without a server):

```bash
node -e "
const fs = require('fs');
const data = fs.readFileSync('data/latin-squares.json', 'utf8');
fs.writeFileSync('js/latin-squares-data.js',
  '// Auto-generated by scripts/generate-latin-squares.js — do not hand-edit.\n' +
  'const LATIN_SQUARES_DATA = ' + data + ';\n');
"
```

## Running locally

No build step or dependencies. Either open `index.html` directly in a browser, or serve the
folder so relative paths behave the same as they will on GitHub Pages:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deploying to GitHub Pages

1. Push this repo to GitHub.
2. In **Settings → Pages**, set the source to the `main` branch, root folder.
3. Your site will be live at `https://<username>.github.io/<repo>/`.

No build pipeline needed — it's plain HTML/CSS/JS.

## Notes on the implementation

- **State persistence**: answers, current question, and the timer are kept in
  `sessionStorage`, so an accidental refresh mid-attempt doesn't lose progress — but nothing
  persists once the tab is closed, and nothing ever leaves the browser.
- **Timer**: counts down from 25:00 and auto-submits when it hits zero, matching the "guess if
  unsure, no going back once time's up" spirit of the real exam.
- **Accessibility**: grid/answer cells are keyboard-focusable buttons; font-size controls scale
  the whole exam UI.
